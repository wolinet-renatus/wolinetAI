## 产品介绍

**WAP (Wolinet AI Panel)** 面向团队与开发者提供统一自主的 AI 自助入口，支持自助申请 API Key、实时查看配额用量、安装与管理 Skills 以及集成 MCP 扩展能力。

底层通过 **Lango Gateway** 统一路由调度，保障模型自主可控与访问安全。

## 主要功能

- **API Key 配额管理**：面向团队成员提供 API Key 申请、限额查询、密钥轮转与撤销能力。
- **模型广场 (Model Arena)**：统一展示 Wolinet Lango 网关聚合的全部可用模型，透明呈现能力基准与延时状态。
- **技能市场 (Skills Hub)**：展示经过审核上架的 AI 技能，支持分类浏览、搜索、一键安装与 skillctl 联动。
- **MCP 市场 (MCP Catalog)**：集中管理符合 Model Context Protocol 规范的服务与工具连接器。
- **技能提报与审核流**：支持开发者上传自定义技能包，管理员进行自动化校验与审核发布。
- **统一运维管理后台**：提供组织管理、成员权限、单点登录 (SSO) 与 Lango 网关配置，全面满足企业级治理要求。
