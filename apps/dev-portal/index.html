01 / 03

The gateway speaks the OpenAI API format. Point an existing client at Lango and choose a model.

PYTHON / OPENAI SDK 
from openai import OpenAI

client = OpenAI(
    base_url="https://lango.wolinet.com/v1",
    api_key="YOUR_WOLINET_KEY",
)

response = client.chat.completions.create(
    model="wolinex-coder",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
