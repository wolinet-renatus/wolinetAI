# Cyber Space Defender Pro

An upgraded, feature-rich arcade retro space shooter with built-in Web Audio synthesis, epic multi-phase boss encounters, powerups, tactical EMP bombs, and high-score persistence.

## 🚀 Newly Added Features

1. **Epic Boss Battles:**
   - Giant Alien Mothership arrives on milestone waves (every 3 waves) with dedicated health gauges, radial bullet spreads, and high reward payouts.
2. **Enemy Retaliation & Projectiles:**
   - Hostiles now fire plasma bolts at the player, adding a bullet-hell evasion dimension.
3. **Collectable In-Game Powerups:**
   - **Spread Shot [S] (Purple):** Triple-directional high-spread laser cannons.
   - **Rapid Fire [R] (Cyan):** Doubled fire rate machine-gun lasers.
   - **Defense Shield [D] (Green):** Glowing protective forcefield that absorbs direct damage.
   - **EMP Bomb [B] (Amber):** Restores EMP screen-clearing bombs.
4. **Tactical EMP Nukes:**
   - Press `B` or `E` to detonate a screen-clearing tactical EMP with screen shake that wipes all standard enemies and heavily damages the boss.
5. **Synthesized Sound Effects:**
   - Zero-external-dependency audio using the HTML5 Web Audio API (lasers, explosions, powerup chimes, and EMP booms) with an in-game mute toggle.
6. **High-Score Persistence & Floating Combat Text:**
   - Saves all-time record score to `localStorage`.
   - Dynamic floating notifications for wave announcements, powerup pickups, and boss alerts.
7. **Pause System:**
   - Press `P` anytime to pause and resume the battle.

## 🎮 How to Play
Open `index.html` in your browser:
```bash
open /Users/apple/Documents/wolinetai/apps/simple-game-app/index.html
```

### Controls:
- **Move Left / Right:** `A` / `D` or `Left Arrow` / `Right Arrow`
- **Fire Laser:** `Spacebar` or `Mouse Click`
- **EMP Nuke:** `B` or `E`
- **Pause / Resume:** `P`
