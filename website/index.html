Client SDKs

Official Client Libraries & Developer Tooling

Integrate Wolinet AI directly into your stack. Strongly typed, high-performance client libraries for TypeScript, Python, and Go with real-time SSE streaming, model discovery, and platform telemetry.

TS / JS

@wolinet/sdk

v1.1.0

Zero-dependency client library compatible with Node.js, Bun, Deno, and modern browsers. Full TypeScript types and async iterators for streaming.

pnpm add @wolinet/sdk (or npm / bun) 
import { WolinetAI } from '@wolinet/sdk';

const client = new WolinetAI({ apiKey: 'YOUR_KEY' });
for await (const chunk of client.chat.completions.stream({
  model: 'wolinex-coder',
  messages: [{ role: 'user', content: 'Say hello' }]
})) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}
Python

wolinet

v1.1.0

Dual synchronous (<code>WolinetAI</code>) and asynchronous (<code>AsyncWolinetAI</code>) client with Pydantic type models and HTTPX keep-alive pooling.

pip install wolinet 
from wolinet import WolinetAI

client = WolinetAI(api_key="YOUR_KEY")
for chunk in client.chat.completions.create(
    model="wolinex-coder",
    messages=[{"role": "user", "content": "Say hello"}],
    stream=True
):
    print(chunk.choices[0].delta.content or "", end="", flush=True)
Go

wolinet-go

v1.1.0

Idiomatic Go client with context cancellation, real-time SSE event channels, and native status telemetry inspection.

go get github.com/wolinet/wolinet-go 
client := wolinet.NewClient("YOUR_KEY")
stream, _ := client.CreateChatCompletionStream(ctx, wolinet.ChatCompletionRequest{
    Model: "wolinex-coder",
    Messages: []wolinet.ChatMessage{{Role: "user", Content: "Say hello"}},
})
for chunk := range stream {
    fmt.Print(chunk.Choices[0].Delta.Content)
}
